PhishGuard demo pages

Safe, local pages that trigger PhishGuard's form detectors. Nothing here sends data anywhere: every "attacker" endpoint is example.net, a domain reserved for documentation.

  • Login form that posts your password to another site
  • Login form that posts over plain HTTP
  • Form whose action is swapped by JavaScript after load
  • A normal login form (should stay quiet)

URL-based detectors (lookalike domains like paypa1.com) are skipped on localhost, so they're covered by the unit tests instead. See the README for how to try them in the browser with a hosts-file entry.
